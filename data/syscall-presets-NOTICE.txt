Re-extract the same pinned factual pairs (network required):
  python -I tools/gen_syscall_presets.py --refresh
Re-capture the same exact fixtures on Windows (requires Rust, no IDA):
  python -I tools/gen_syscall_presets.py --capture <ntdll.dll> <win32u.dll>
The capture verifies both SHA-256 values, both file versions and the parser
source hash before replacing the captured tables. Inputs changing during the
capture are rejected. --refresh preserves the separately captured tables.

Compare explicit fixture DLLs without IDA or network access:
  cargo run -p ntrays-core --example check_syscall_preset -- <preset-id> <ntdll.dll> <win32u.dll>
Exit 0 means exact equality, 1 reports table differences, and 2 is invalid input.
